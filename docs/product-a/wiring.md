# 接线说明 · 产品 A

## ⚠️ 安全提醒

> **继电器触点涉及强电（220V AC），接线时请务必断开总电源，操作不当有触电危险！**
> 如果你不确定如何接线，请咨询电工。本产品仅作开发/评估使用，量产前需经过安全认证。

## 端子定义

板子上有两组绿色接线端子：

| 端子 | 标识 | 说明 |
|------|------|------|
| J1 | L IN / N IN | 交流电输入（接墙上火线、零线） |
| J2 | L1 OUT / N OUT | 继电器 1 输出（接灯具的 L / N） |
| J3 | L2 OUT / N OUT | 继电器 2 输出（接第二路灯具的 L / N） |
| J4 | 3V3 / GND / TX / RX | 调试串口（3.3V TTL，<b>不要接 5V</b>） |

## 典型接线

```
墙上火线(L) ──┬─── L IN ──┐
              │            │
墙上零线(N) ──┼─── N IN ──┼─── N OUT ── 灯具/插座 N
              │            │
              │        L1 OUT ── 灯具1 L (继电器1控制)
              │        L2 OUT ── 灯具2 L (继电器2控制)
```

**简单说**：
- 墙上火线进 `L IN`，两个灯的火线分别接 `L1 OUT` / `L2 OUT`
- 零线在板子内部是直通的，两个灯共用一根零线从 `N OUT` 回去

## USB 供电 vs 外接 5V

- **只测试继电器以外的功能**（如配网、串口调试）：直接 Type-C 接电脑即可
- **继电器要动作**：建议外接 5V/2A 电源到 Type-C 或 5V/GND 排针，电脑 USB 电流可能不足
- **测量电流/功率**：必须接通 J1 端子的 220V 交流电
