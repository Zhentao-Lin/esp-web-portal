# 快速上手 · 产品 A

5 分钟把你的智能开关用起来。

## 1. 硬件准备

- 产品 A 开发板 ×1
- **USB 数据线**（必须是带数据传输能力的，不是只能充电的线）
- 5V 供电（USB 即可，继电器工作时建议外接 5V/2A）
- 一盏普通台灯 / LED 灯泡（用于测试继电器）

## 2. 烧录固件

👉 **打开在线烧录页**：<a href="/flash/?product=product-a" target="_blank">⚡ 在线烧录产品 A 固件</a>

按页面提示：
1. 选择最新的固件版本（默认已经选中产品 A）
2. 用 USB 线连接开发板到电脑
3. 按住板子上的 **BOOT** 键不放
4. 点击「连接并烧录」，在弹窗中选择对应的串口（CP210x / CH340 开头的）
5. 看到"烧录成功"提示即可

详细烧录排错见 [固件说明 / 烧录](product-a/firmware)。

## 3. 配网

烧录完成后，开发板会重启进入 AP 配网模式：

1. 手机连接名为 `SwitchAP-xxxx` 的 Wi-Fi（无密码）
2. 浏览器会自动弹出配网页（没弹出则访问 `192.168.4.1`）
3. 选择你家的 Wi-Fi，输入密码，点击连接
4. 开发板连上 Wi-Fi 后会显示获得的 IP

## 4. 控制继电器

在电脑/手机浏览器里打开开发板的 IP 地址，进入 Web 控制台：

- 点 **Relay 1 ON/OFF** 控制第 1 路继电器
- 点 **Relay 2 ON/OFF** 控制第 2 路继电器
- 页面实时显示电压、电流、功率

把台灯接到继电器端子上（先断电！），点一下 ON，灯就亮了 ✨
