# 快速上手 · 产品 B

## 1. 烧录固件

👉 **打开在线烧录页**：<a href="/flash/?product=product-b" target="_blank">⚡ 在线烧录产品 B 固件</a>

1. 选择最新版本（默认已选中产品 B）
2. 用 USB 线连接板子到电脑
3. 按住 **BOOT** 键，点「连接并烧录」
4. 烧录成功后松开 BOOT

## 2. 配网

烧录完成后板载蓝灯会慢闪，进入配网模式：
1. 手机连接 Wi-Fi：`SensorB-xxxx`（无密码）
2. 浏览器访问 `192.168.4.1`
3. 输入家里的 Wi-Fi 和 MQTT Broker 地址
4. 保存后设备会自动重启，连网后蓝灯熄灭

## 3. 在 Home Assistant 里看到数据

配置好 MQTT 后，设备会自动出现在 HA 的 MQTT 设备列表里（自动发现）：
- 3 个传感器：温度 (°C) / 湿度 (%) / 光照 (lx)
- 1 个诊断：电池电压 / 信号强度

数据默认每 60 秒上报一次。

## 4. 电池使用

插上 3.7V 锂电池后设备会自动切到电池供电，蓝灯熄灭进入低功耗模式。
通过 Type-C 供电时会自动给电池充电（红灯亮 = 充电中，熄灭 = 充满）。
