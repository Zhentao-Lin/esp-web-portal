# 产品 B · 环境传感器

> ESP32-C3 超低功耗温湿度 + 光照节点 · 电池供电 · 支持 MQTT / Home Assistant

- **主控芯片**：ESP32-C3-MINI-1（4MB Flash）
- **传感器**：SHT30（温湿度）+ BH1750（光照）
- **供电**：Type-C 5V 或 3.7V 锂电池（板载 TP4056 充电）
- **续航**：深度休眠 + 1 分钟上报一次，2000mAh 电池可工作 **约 6 个月**
- **板载按键**：BOOT ×1，USER ×1
- **板载 LED**：蓝色状态 LED ×1
