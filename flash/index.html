⚡ 固件在线烧录

选择产品和固件版本，通过 USB 连接开发板，在浏览器里一键烧录。无需安装 Arduino IDE / esptool。

⚠️ 当前浏览器不支持 Web Serial API。请使用最新版 Chrome / Edge 浏览器（桌面端或 Android Chrome）。

① 选择固件

查看/替换要烧录的 bin 文件

如果固件链接因跨域问题无法在线拉取，可以先把 bin 下载到本地，然后点下方"选择本地文件"替换（文件名需与原文件一致）。

② 连接开发板

  1. 用 USB 数据线连接电脑和开发板（注意：必须是能传数据的线，不是只能充电的线）。
  2. 如果是 ESP32 开发板，按住 BOOT 键不放。部分板子需要先按 EN/RST 再按 BOOT。
  3. 点击下方"连接"按钮，在浏览器弹窗里选择你的开发板对应的串口。
